## 1. 背景

当前项目中与光功率/光强相关的逻辑分散在两个位置：

- `PowerReadoutController`：光功率计面板读数，当前主要根据接收器微调偏差使用高斯衰减模型计算。
- `RecordManager`：填表场景中的电压-功率数据，当前使用理想电光调制曲线 `I = Imax * sin²(pi * V / 2Vpi)`。

这会导致两个问题：

1. 光功率计面板显示的读数与后续填表数据来源不一致。
2. 当前填表公式过于理想，未体现实际光功率计读数中的零点、消光残余和接收效率。

本次需求目标是统一光功率计面板显示和实验数据处理所使用的读数模型，使仿真既符合电光效应实验的数据处理逻辑，又保留真实仪器读数的基本误差特征。

---

## 2. 实际实验数据定义

实际电光效应实验中，学生记录的通常不是抽象的“理论光强”，而是光功率计或光电探测器在接收端输出的读数：

- 若使用光功率计，记录值通常为光功率，单位如 `uW`、`mW`。
- 若使用光电探测器加电压表/示波器，记录值可能是与光功率成正比的电压或电流。
- 教学讲义中常将这些读数统称为“光强”，本质上是接收端光功率的相对量或等比例量。

光功率计自身不使用电光效应公式计算读数；它通过探测器响应和波长校准把入射光转换为功率读数。仿真中需要计算的是“到达探头的光功率”，再将其作为仪器读数展示和记录。

参考资料：

- VIAVI Optical Power Meter principle: https://www.viavisolutions.com/zh-cn/what-optical-power-meter
- Electro-optic modulator transmission formula: https://www.fiberoptics4sale.com/blogs/wave-optics/electro-optic-modulators-2

## 3. 需求目标

### 3.1 统一读数来源

光功率计面板显示值与后续填表/数据处理使用同一套读数模型。

### 3.2 使用接近实际实验的光功率模型

填表数据不再直接使用纯理想光强 `Imax * sin²(...)`，而是使用带零点、消光残余和接收效率的光功率读数：

```text
P_read(V) = P_dark + eta_align * P_scale * [leakage + visibility * sin²(phi0 + pi * V / 2Vpi)]
```

其中：

| 参数 | 含义 |
|------|------|
| `P_read` | 光功率计读数，用于面板显示和填表 |
| `V` | 当前外加电压 |
| `Vpi` | 半波电压 |
| `P_dark` | 背景光/暗电流/仪器零点 |
| `P_scale` | 有效最大光功率标尺 |
| `eta_align` | 接收器对准效率，范围 `[0, 1]` |
| `leakage` | 偏振片消光不完全、杂散光等残余透过项 |
| `visibility` | 调制度 |
| `phi0` | 静态相位偏置 |

对于理想教学模式，可使用退化形式：

```text
P_read(V) = P_dark + eta_align * P_scale * sin²(pi * V / 2Vpi)
```

### 3.3 接收器微调只影响接收效率

接收器 WASD 微调不改变电光调制曲线的周期和相位，只影响整体接收效率 `eta_align`：

```text
eta_align = exp(-beamFocus * r²)
r² = receiverDevX² + receiverDevY²
```

这表示接收器越偏离光路中心，收到的总光功率越低。

### 3.4 数据处理使用光功率计读数

后续实验数据处理应使用 `P_read`，即光功率计显示并记录的接收端光功率/相对光强。

数据处理包括：

- 记录不同电压 `V` 下的光功率计读数 `P_read`
- 绘制 `P_read - V` 曲线
- 根据极大值、极小值或相邻极值点间距确定半波电压
- 可选计算消光比、调制度等实验指标

## 4. 用户故事

### 4.1 学生调节接收器

作为学生，我希望在光功率计面板中看到接收器对准程度带来的读数变化，从而理解光路对准会影响实际接收功率。

验收：

- 接收器未开启时读数为 0 或面板隐藏。
- 接收器开启后读数来自当前电压下的光功率模型。
- 接收器微调偏离中心时，读数整体降低。

### 4.2 学生调节电压并填表

作为学生，我希望填表数据与光功率计面板读数一致，从而按照真实实验流程“读仪器、记数据、作曲线”完成实验。

验收：

- 表格记录的功率值与面板当前稳定读数一致。
- 改变电压后，读数按电光效应 `sin²` 曲线变化。
- 相邻极大/极小点位置可用于后续半波电压分析。

### 4.3 教师/开发者配置实验真实度

作为教师或开发者，我希望能控制仿真读数的理想程度，以便在不同教学阶段使用。

验收：

- 可配置 `P_dark`、`leakage`、`visibility`、`phi0`、噪声强度。
- 默认参数应适合教学，不让噪声影响学生读数和填表。
- 可一键退化为理想 `sin²` 曲线。

## 5. 功能需求

### 5.1 光功率计面板

- 面板显示单位建议使用 `uW`。
- 面板读数使用 `P_read(V)`。
- 面板可显示轻微实时抖动，但不应影响填表的确定性。
- 面板在接收器监控模式和微调模式下都应显示当前读数。
- 接收器关闭时不显示读数或显示 0。

### 5.2 填表数据

- 表格记录值使用无随机抖动的稳定 `P_read(V)`。
- 表格列名建议使用“光功率/uW”或“相对光功率”。
- 如 UI 继续使用“光强”，应在文档或提示中说明其为光功率计读数的相对量。

### 5.3 数据处理

- 后续实验处理使用 `P_read`。
- 不能使用接收器偏移量、理论归一化光强或随机噪声值作为数据处理输入。
- 若启用 `P_dark` 和 `leakage`，极值分析应允许 `P_min > 0`。

### 5.4 参数默认值建议

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `P_dark` | `0.2 uW` | 仪器零点/背景光 |
| `P_scale` | `198.5 uW` | 沿用现有最大读数 |
| `leakage` | `0.01` | 约 1% 残余透过 |
| `visibility` | `0.99` | 与 leakage 配合，使曲线接近理想但不为 0 |
| `phi0` | `0` | 默认零电压消光 |
| `noiseAmplitude` | `0.2 uW` | 仅用于面板显示，可关闭 |
| `beamFocus` | 沿用现有值 | 接收器对准灵敏度 |

---

## 6. 非功能需求

- 读数计算应为确定性纯计算，便于测试。
- 面板噪声与填表稳定值应分离。
- 保持现有场景 Inspector 参数尽量兼容，避免破坏序列化。
- 保留现有接收器状态机交互方式。
- 不要求本次修改真实模拟光功率计内部电路、响应度曲线和量程切换。

---

## 7. 不在本次范围内

- 不实现真实探头波长响应曲线。
- 不模拟光功率计量程自动切换。
- 不模拟探测器饱和、温漂和长期零漂。
- 不重构整体 UI。
- 不修改电光晶体核心 DLL。

---

## 8. 验收标准

1. 光功率计面板和填表记录使用同一稳定读数模型。
2. 电压变化时，读数随 `sin²(phi0 + pi * V / 2Vpi)` 规律变化。
3. 接收器微调只改变读数幅度，不改变半波电压周期。
4. 填表记录不包含随机噪声。
5. 极小值允许大于 0，以体现实际消光不完全和背景读数。
6. 关闭真实度参数后，可得到理想 `sin²` 教学曲线。
7. 后续数据处理能够直接使用表格中的 `P_read` 求半波电压。
