一、实验目的

  1. 掌握晶体线性电光效应（普克尔效应）的核心原理，理解电光调制对光传播特性的调控机制。
  2. 观测正交偏振光路下，输出光强随外加驱动电压的变化规律，明确电光调制的传输特性。
  3. 分别采用极值法与交流调制法测量晶体的半波电压，对比两种方法的测量精度、优缺点及适用场景。
  4. 完成电光调制的光通信演示实验，验证电光效应在光信号传输中的工程应用，加深对光纤通信核心技术的理解。

实验背景与意义

电光效应是光电子技术的核心物理效应之一，其中线性电光效应因响应速度快、调制带宽大、功耗低的优势，成为现代光通信、激光雷达、量子信息等领域的核心技术基础。电光调制器作为光通信系统的核心器件，可通过电场快速调控光的强度、相位与偏振态，实现电信号到光信号的高速转换，支撑了长距离、大容量光纤通信系统的运行。

本实验通过虚拟仿真平台完成电光效应的核心测量与应用演示，可规避高压操作、精密光路调节的实操风险，同时完整复现电光调制的物理过程，为掌握光电子器件的工作原理与工程应用提供实验支撑。

二、实验原理

2.1 晶体的线性电光效应

电光效应是指晶体在外加电场作用下，折射率张量发生变化，进而改变光在晶体中传播特性的物理现象。其中线性电光效应（普克尔效应）指晶体折射率的变化与外加电场强度呈线性关系，仅存在于无对称中心的压电晶体中。本实验采用铌酸锂晶体，是典型的线性电光晶体。

当线偏振光沿晶体光轴方向入射，且外加电场沿晶体横向施加时，晶体的光学各向异性发生改变，原有的光轴方向出现感应双折射，入射的线偏振光被分解为沿两个感应主轴振动的 o 光（寻常光）与 e 光（非寻常光），两束光在晶体中传播产生相位差。

2.2 电光调制的光强传输公式

本实验采用正交偏振光路，核心结构为：激光器 → 起偏器 → 电光晶体 → 检偏器 → 光电探测器。

  • 起偏器将激光器输出的自然光变为线偏振光，其偏振方向与晶体感应主轴成 45°，确保 o 光与 e 光的振幅相等。
  • 检偏器与偏振方向正交，将 o 光与 e 光的振动分量投影到同一方向，产生偏振干涉。
公式占位

两束光的相位差由外加电压决定，后续可补入相位差公式和透过率公式。

δ = πU / Vπ

I / I₀ = sin²(δ / 2) = sin²(πU / 2Vπ)

该式为电光调制的核心传输公式，表明输出光强随外加电压呈正弦平方规律周期性变化。

2.3 半波电压的物理定义

半波电压是电光晶体的核心特征参数，定义为：使晶体中 o 光与 e 光产生 π 相位差所需的外加驱动电压。从传输特性看，相邻光强极大值与极小值对应的电压差值，即为半波电压。

2.4 两种半波电压测量方法的原理

（1）极值法（直流测量法）

对晶体施加连续可调的直流偏置电压，逐点记录输出光功率随电压的变化，绘制光功率 - 电压特性曲线。根据传输公式，曲线中相邻的光强极小值与极大值对应的电压之差即为半波电压，通过多组极值点的测量取平均值，可提升测量精度。该方法为静态测量，原理直观、操作简单，是电光晶体参数测量的基础方法。

（2）交流调制法（动态测量法）

在直流偏置电压的基础上，对晶体叠加小幅低频正弦交流调制信号，将驱动信号与光电探测器的输出信号同时接入示波器，对比输入与输出信号的波形特征。当工作点位于调制曲线线性区时，输出信号与输入交流信号同频，波形无失真；当工作点位于调制曲线极值点时，输出信号频率为输入信号的 2 倍，出现倍频失真。因此，相邻两个倍频失真点的电压差值即为半波电压。

三、实验步骤

3.1 光路系统调节

  1. 激光器调节：开启虚拟实验平台的激光器电源，预热 3 分钟，调整激光器的空间位置，使输出激光束沿水平光路传播，光斑稳定投射在白屏中心。
  2. 起偏器与检偏器调节：依次在光路中放入起偏器与检偏器，先旋转使输出光强最大；再旋转至消光状态，此时起偏器与检偏器处于正交偏振状态。
  3. 电光晶体调节：在起偏器与检偏器之间放入铌酸锂电光晶体，调整晶体空间位置与轴向角度，使激光束沿晶体光轴方向垂直入射，并确保晶体感应主轴与起偏器偏振方向成 45°。
  4. 光电探测器校准：将白屏替换为光电探测器，微调光路各元件的位置，使探测器接收到的光功率最大，完成光路对准与校准。

3.2 极值法测量半波电压

  1. 关闭交流信号源，将晶体驱动电极连接至直流高压源，设置电压调节范围为 0~700V，调节步长为 50V。
  2. 从 0V 开始逐步升高直流电压，每调整一次电压，待示数稳定后，记录对应的直流电压值与光电探测器输出的光功率值，直至电压升至 700V。
  3. 基于测量数据，绘制光功率与直流电压的关系曲线，定位曲线中的光强极大值与极小值点，计算相邻极值点的电压差，取平均值得到极值法测量的半波电压。

3.3 交流调制法测量半波电压

  1. 将直流高压源与交流信号源并联接入晶体驱动电极，设置交流信号为 1kHz 正弦波，幅值为 20V，将交流驱动信号接入示波器 CH1 通道，光电探测器输出信号接入 CH2 通道。
  2. 从 0V 开始逐步调节直流偏置电压，同时观察示波器两路波形，当 CH2 通道输出波形出现严格倍频失真时，记录此时的直流偏置电压值。
  3. 继续升高直流电压，依次记录所有出现倍频失真的直流偏置电压点，计算相邻倍频点的电压差，取平均值得到交流调制法测量的半波电压。

3.4 光通信演示拓展实验

  1. 将音频信号源接入电光调制系统，替代原有低频交流信号，将光电探测器输出端连接至扬声器。
  2. 调节直流偏置电压至线性工作点，开启音频信号源，此时扬声器可清晰播放音频信号，验证电光调制实现了电信号 - 光信号 - 电信号的转换传输。
  3. 调整直流偏置电压至极值点附近，观察音频信号失真现象；用遮光板遮挡光路，扬声器声音立即消失，验证光信号是音频信息的传输载体。

5.3 调制特性与倍频失真分析

  1. 电光调制的特性曲线呈周期性正弦平方分布，与理论传输公式匹配。光功率随电压变化呈现周期性增强与减弱。
  2. 倍频失真的本质是调制曲线极值点处的非线性：当工作点位于极值点时，光强对电压的一阶导数为 0，二阶导数主导输出，因此输入正弦信号时，输出信号以二次谐波为主，出现倍频现象。该现象可精准定位调制曲线的极值点，避免极值法中人工判断光强极值的主观误差。

5.4 误差分析

本实验为虚拟仿真实验，无实际操作中的环境干扰与仪器随机误差，测量结果应与理论值保持一致。在实际实操实验中，主要误差来源如下：

（1）系统误差

  • 偏振片消光比不足：起偏器与检偏器无法实现完全消光，导致光强极小值不为 0，极值点定位出现偏差。
  • 晶体轴向偏差：晶体感应主轴与起偏器偏振方向偏离 45°，导致 o 光与 e 光振幅不等，调制曲线对比度下降。
  • 仪器误差：直流高压源示数误差、光电探测器非线性响应，会影响电压与光功率的测量精度。

（2）偶然误差

  • 温度漂移：晶体折射率与电光系数随温度变化，导致半波电压发生漂移。
  • 环境干扰：光路机械振动、外界杂散光入射，会导致光功率测量值出现波动。
  • 主观误差：极值法中人工判断光强极大 / 极小值的主观偏差，会导致极值点电压记录错误。

（3）减小误差的方法

  • 实验前对仪器进行预热与校准，保证电压源与光功率计示数稳定。
  • 精确调节晶体轴向与偏振片角度，提升调制曲线的消光比与对比度。
  • 采用多组测量取平均值的方法，减小人工读数的偶然误差。
  • 控制实验环境温度与振动，降低外界干扰影响。

六、实验结论

  1. 本实验完整验证了晶体的线性电光效应，观测到正交偏振光路下，输出光强随外加驱动电压呈正弦平方规律的周期性变化，明确了电光调制的核心传输特性。
  2. 采用极值法与交流调制法完成了铌酸锂晶体半波电压的测量，两种方法的测量结果应与晶体理论标称值吻合，验证两种测量方法的准确性。
  3. 极值法原理直观、操作简单，适用于电光晶体半波电压的静态标定；交流调制法通过倍频失真现象精准定位极值点，抗干扰能力强，适用于电光调制器动态性能测试与在线校准。
  4. 光通信演示实验验证了电光调制技术的工程应用价值：当工作点设置在线性区时，电光调制可实现音频信号的无失真传输，遮挡光路后信号传输中断，直观复现光纤通信系统中“电 - 光 - 电”的信号转换与传输过程。
