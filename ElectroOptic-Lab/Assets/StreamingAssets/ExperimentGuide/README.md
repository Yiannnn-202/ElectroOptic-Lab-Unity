# Scene2 realtime guide GIF assets

Place the following optional assets in this directory:

- `PlaceScreen.gif`
- `CalibrateLaser.gif`
- `VerifyExtinction.gif`
- `ObserveConoscopic.gif`
- `InstallPowerMeterProbe.gif`
- `InstallPhotodiodeProbe.gif`

Recommended maximum per file: 960×540, 20 fps, 30 seconds, 20 MB. Missing files are handled by the in-game placeholder.
