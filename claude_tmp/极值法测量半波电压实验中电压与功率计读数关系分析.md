# 极值法测量半波电压实验中电压与功率计读数关系分析

## 实验原理概述

极值法是测量电光晶体半波电压（V_π）的常用实验方法。通过改变施加在晶体上的电压，观察输出光强的变化，当光强达到极值（最大值或最小值）时，对应的电压与半波电压存在确定关系。

### 物理原理
在典型的电光调制实验中，晶体置于正交偏振器之间，输出光强与施加电压的关系为：

```
I = I₀ × sin²(πV/(2V_π))
```

其中：
- **I**: 输出光强（功率计读数）
- **I₀**: 最大光强（电压为V_π时的光强）
- **V**: 施加电压
- **V_π**: 半波电压（产生π相位差所需电压）

### 极值点特性
根据公式分析：
- 当 `V = 0` 时，`I = 0`（消光状态）
- 当 `V = V_π` 时，`I = I₀`（第一次最大值）
- 当 `V = 2V_π` 时，`I = 0`（第一次最小值）
- 当 `V = 3V_π` 时，`I = I₀`（第二次最大值）

**实验方法**：逐步改变电压，记录对应的光强值，寻找光强最大值对应的电压，该电压即为半波电压V_π。

#### 核心参数配置：
```csharp
public float currentVoltage = 0.0f;   // 当前外加电压 (V)
public float voltageStep = 10.0f;     // 每次按键增减的电压量
public float halfWaveVoltage = 150.0f; // 半波电压 (V_π) - 可在面板调节
public float maxIntensity = 100.0f;    // 最大光强 (I₀) - 可在面板调节
```

#### 电压-光强关系算法：
```csharp
// 🌟 核心公式：光强度电光调制公式
float CalculateReceiverValue(float voltage)
{
    // 公式: I = I_0 * sin^2( (PI * u) / (2 * u_pi) )
    // 1. 计算括号里的相位值
    float phase = (Mathf.PI * voltage) / (2f * halfWaveVoltage);

    // 2. 计算 sin 的平方，再乘以最大光强
    float result = maxIntensity * Mathf.Pow(Mathf.Sin(phase), 2);

    return result;
}
```

#### 实验操作接口：
- **电压控制**：按`A`键减少电压，按`D`键增加电压（步长10V）
- **数据记录**：点击记录按钮将当前电压和对应光强值填入表格
- **实时显示**：UI实时显示当前电压和计算得到的光强值

```csharp
private void UpdateVpiDisplay(float sensitivity)
{
    // sensitivity 来自晶体物理核心计算
    double lambda = _config.profile.defaultWavelength_nm * 1e-9;
    double L = _length_mm * 1e-3;
    double d = _thickness_mm * 1e-3;
    double v_pi = 0.0;

    if (_modMode == ModulationMode.Transverse)
        v_pi = (lambda * d) / (2.0 * L * sensitivity);  // 横向调制V_π公式
    else
        v_pi = lambda / (2.0 * sensitivity);             // 纵向调制V_π公式

    txtVpiValue.text = $"Vπ: {v_pi:F0} V";
}
```

```csharp
// 功率计读数计算（独立于RecordManager）
private void CalculatePower()
{
    float noise = (Mathf.PerlinNoise(Time.time * 5f, 0f) - 0.5f) * 0.5f;

    if (currentMode == 0)  // 接收器微调模式
    {
        // 基于接收器位置偏差的高斯衰减模型
        float rSquared = receiverDevX * receiverDevX + receiverDevY * receiverDevY;
        currentPower = maxPowerReceiver * Mathf.Exp(-beamFocus * rSquared) + noise;
    }
    else
    {
        currentPower = 0f;  // 未调节状态
    }
}
```

**重要发现**：功率计系统与RecordManager的实验公式**独立运行**，两者没有直接数据连接。

## 系统架构分析

### 双轨并行设计
项目采用了两套独立的测量系统：

#### 1. 理论实验系统 (RecordManager)
- **目的**：演示极值法测量原理
- **数据源**：基于理论公式 `I = I₀ sin²(πV/(2V_π))` 计算
- **交互**：通过A/D键改变电压，记录数据表格
- **显示**：UI直接显示计算值

#### 2. 实际测量系统 (PowerReadoutController)
- **目的**：模拟实际光学测量过程
- **数据源**：基于接收器位置偏差的物理模拟
- **交互**：通过WASD键微调接收器位置
- **显示**：模拟真实功率计读数（含噪声）

### 设计意图分析
这种双轨设计体现了**教学仿真**的特点：
1. **理论演示**：清晰展示物理公式和实验原理
2. **实践模拟**：让用户体验实际测量中的对准误差和噪声
3. **解耦设计**：避免复杂物理计算影响教学演示的清晰度

## 数学关系模型

### 1. 理论关系（RecordManager）
```
接收器读数 = maxIntensity × sin²(π × currentVoltage / (2 × halfWaveVoltage))
```

**参数默认值**：
- `maxIntensity = 100.0` （最大光强）
- `halfWaveVoltage = 150.0` （半波电压）

**特性曲线**：
| 电压(V) | 相位(rad) | sin²(相位) | 读数 |
|---------|-----------|------------|------|
| 0       | 0         | 0          | 0    |
| 75      | π/4       | 0.5        | 50   |
| 150     | π/2       | 1.0        | 100  |
| 225     | 3π/4      | 0.5        | 50   |
| 300     | π         | 0          | 0    |

### 2. 实际测量关系（PowerReadoutController）
```
功率计读数 = 198.5 × exp(-20 × r²) + 噪声
```
其中 `r² = Δx² + Δy²` 为接收器位置偏差平方和。

### 3. 两系统对比
| 特性 | 理论系统 (RecordManager) | 实际系统 (PowerReadoutController) |
|------|--------------------------|-----------------------------------|
| 数据来源 | 理论公式计算 | 位置偏差物理模拟 |
| 电压影响 | 直接影响计算结果 | 无直接影响（通过晶体间接影响） |
| 噪声 | 无 | 有（模拟测量不确定性） |
| 对齐误差 | 无 | 有（主要影响因素） |
| 教学目的 | 展示物理原理 | 模拟实际测量过程 |

## 实验操作流程

### 极值法实验步骤（基于RecordManager）

1. **初始化设置**
   - 设置半波电压 `halfWaveVoltage`（默认150V）
   - 设置最大光强 `maxIntensity`（默认100）
   - 设置电压步长 `voltageStep`（默认10V）

2. **电压扫描**
   - 按`D`键增加电压，按`A`键减少电压
   - 观察光强值随电压变化

3. **数据记录**
   - 在关键电压点点击记录按钮
   - 系统自动将（电压，光强）对填入表格

4. **寻找极值点**
   - 记录光强最大值对应的电压
   - 该电压即为实验测得的半波电压V_π

5. **误差分析**
   - 比较测量值与理论值（LabController显示的V_π）
   - 分析误差来源

### 实际测量注意事项（基于PowerReadoutController）
1. 双击接收器开机（变蓝）
2. 单击接收器进入调节模式（变绿）
3. 使用WASD键微调接收器位置，使读数最大
4. 记录最大读数对应的接收器状态

## 系统集成分析

### 当前状态
两个系统**独立运行**，没有数据交换：
- RecordManager使用理论公式计算"接收器读数"
- PowerReadoutController基于位置偏差计算"功率计读数"
- 两者数值范围不同（0-100 vs 0-198.5 μW）
- 没有共享电压或光强数据

### 可能的集成方案
如需实现完整实验流程，可考虑以下集成：

1. **数据连接**：将RecordManager的计算结果传递给PowerReadoutController
2. **统一单位**：将maxIntensity(100)与maxPowerReceiver(198.5)建立换算关系
3. **电压联动**：LabController的电压变化同时影响两个系统
4. **实验模式**：增加"理论演示"和"实际测量"两种实验模式

## 与实际物理实验的对比

### 仿真优势
1. **原理清晰**：直接展示 `I ∝ sin²(πV/(2V_π))` 关系
2. **操作安全**：无高压危险，可随意探索参数
3. **即时反馈**：实时显示计算结果，便于理解
4. **参数可调**：半波电压、最大光强等参数可自由调节

### 仿真局限
1. **简化模型**：忽略晶体实际复杂的光学特性
2. **理想条件**：假设完美偏振器、无散射损耗等
3. **独立系统**：理论计算与实际测量脱节
4. **噪声简化**：仅添加简单随机噪声，未模拟系统误差
