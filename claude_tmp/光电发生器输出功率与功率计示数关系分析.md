# 光电发生器输出功率与功率计示数关系分析

## 项目概述
本项目为电光实验仿真系统，模拟晶体光学实验，包括锥光干涉图案、偏振光传播和电光调制。系统通过物理引擎和原生DLL计算晶体在电场下的光学特性变化。

## 关键组件分析

### 1. 光电发生器 (LaserEmitter)
**文件位置**: `Assets/Scripts/Laser/LaserEmitter.cs`

光电发生器（激光发射器）是系统的光源，负责发射偏振激光束。

#### 关键参数:
- **输出光强**: `intensity = 1.0f` (归一化值，范围0.0-1.0)
- **偏振角度**: `polarizationAngle = 90f` (默认竖直偏振)
- **偏振度**: `dop = 0.9f` (默认部分偏振，0.9表示高度偏振)
- **发射方向**: 沿发射器局部坐标系的-X轴方向

#### 输出特性:
- 生成`LightData`结构体，包含光强、偏振角和偏振度信息
- 通过射线检测(Raycast)寻找实现了`IOpticalReceiver`接口的光学组件
- 使用LineRenderer可视化激光路径

### 2. 光功率计 (PowerReadoutController)
**文件位置**: `Assets/Scripts/PowerReadoutController.cs`

光功率计负责测量并显示接收到的光功率值。

#### 关键参数:
- **最大读数**: `maxPowerReceiver = 198.5f μW`
- **光束聚焦因子**: `beamFocus = 20.0f`
- **调节速度**: `adjustSpeed = 0.2f`
- **初始偏差范围**: `initialDeviationRange = 0.15f`

#### 功率计算算法:
```csharp
private void CalculatePower()
{
    float noise = (Mathf.PerlinNoise(Time.time * 5f, 0f) - 0.5f) * 0.5f;

    if (currentMode == 0)  // 接收器微调模式
    {
        // 接收器调节时的读数变化
        float rSquared = receiverDevX * receiverDevX + receiverDevY * receiverDevY;
        currentPower = maxPowerReceiver * Mathf.Exp(-beamFocus * rSquared) + noise;
    }
    else
    {
        // 未在调节状态时的底噪或归零
        currentPower = 0f;
    }

    if (currentPower < 0) currentPower = 0f;
}
```

#### 工作模式:
- **监控模式** (蓝色状态): 仅显示读数，无法调节
- **微调模式** (绿色状态): 可通过WASD键调节接收器位置，实时改变读数

### 3. 接收器控制器 (ReceiverStateController)
**文件位置**: `Assets/Scripts/Receiver/ReceiverStateController.cs`

管理接收器的状态机，与功率计窗口联动。

#### 状态定义:
- **状态0** (关机): 恢复原色，功率计窗口关闭
- **状态1** (监控): 蓝色高亮，功率计窗口显示监控模式
- **状态2** (调节): 绿色高亮，功率计窗口显示微调模式

#### 交互逻辑:
- 双击: 在关机(0)和监控(1)间切换
- 单击: 在监控(1)和调节(2)间切换

## 数学关系模型

### 1. 理想情况下的关系
当接收器完美对齐时 (`receiverDevX = 0`, `receiverDevY = 0`):

```
功率计读数 = maxPowerReceiver + noise
          = 198.5 μW + 随机噪声
```

### 2. 实际情况下的衰减模型
接收器存在位置偏差时，功率按高斯分布衰减:

```
功率计读数 = maxPowerReceiver × exp(-beamFocus × r²) + noise
```

其中:
- `r² = Δx² + Δy²` (接收器位置偏差的平方和)
- `beamFocus = 20.0` (光束聚焦因子，决定衰减速度)
- `noise ~ Uniform(-0.25, 0.25)` 随机噪声

### 3. 衰减特性分析
- **半高宽位置**: 当 `r² = ln(2)/beamFocus ≈ 0.0347` 时，功率衰减一半
- **有效接收半径**: `r < 0.5` (由clamp函数限制)
- **最小可读功率**: 接近0 μW (当 `r² > 0.35` 时)

## 实验场景中的影响因素

### 1. 接收器对齐精度
- 通过WASD键实时微调接收器位置
- 偏差越大，接收功率衰减越显著
- 模拟实际光学实验中对准精度的要求

### 2. 偏振器衰减 (马吕斯定律)
**文件位置**: `Assets/Scripts/PolarizerPhysics.cs`

当激光通过偏振器时，光强按马吕斯定律衰减:

```
最终光强 = 非偏振部分 + 偏振部分 × cos²(Δθ)
```

其中:
- 非偏振部分: `intensity × (1 - dop) × 0.5`
- 偏振部分: `intensity × dop × cos²(偏振器角度 - 入射光偏振角)`

### 3. 晶体调制效应
虽然晶体物理核心 (`CrystalPhysicalCore.cs`) 主要计算折射率变化和旋转矩阵，不直接改变光强，但通过改变光的偏振状态间接影响后续偏振器的透过率。

## 系统架构特点

### 1. 解耦设计
- 功率计独立计算，不直接接收光强数据
- 通过位置偏差模拟实际接收功率
- 与晶体选中状态完全解耦

### 2. 模拟真实性
- 高斯衰减模型模拟光束空间分布
- 随机噪声模拟测量不确定性
- 交互式微调增强实验沉浸感

### 3. 实验教学价值
- 直观展示对准精度对测量结果的影响
- 模拟实际光学测量中的各种误差源
- 提供可交互的调试环境

## 关键发现

1. **归一化设计**: 光电发生器输出为归一化强度(0-1)，功率计显示实际μW值
2. **位置敏感**: 功率计读数主要取决于接收器对准精度，而非光源绝对功率
3. **间接耦合**: 系统通过位置偏差间接模拟实际光强接收，而非直接传递光强数据
4. **教学导向**: 设计重点在于展示光学实验原理，而非精确物理仿真

## 建议与改进方向

1. **增强物理一致性**: 可将激光器`intensity`参数与`maxPowerReceiver`关联，建立直接换算关系
2. **扩展测量模式**: 增加绝对功率测量、相对功率测量等不同模式
3. **误差分析**: 加入系统误差、随机误差的定量分析功能
4. **数据记录**: 增加功率随时间变化的数据记录和导出功能

## 结论

本项目中的光电发生器输出功率与功率计示数关系采用**教学导向的简化模型**：
- 光电发生器输出归一化光强
- 功率计读数基于接收器位置偏差的高斯衰减模型
- 最大读数对应理想对准情况下的理论接收功率
- 实际读数模拟实验中对准误差导致的功率损失

这种设计平衡了计算效率、交互体验和教学价值，适合电光实验的教学仿真场景。
