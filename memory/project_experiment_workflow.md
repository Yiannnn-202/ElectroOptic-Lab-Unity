## 电光效应实验完整流程（Scene2.The Lab 主实验场景）

### 第一步：放置光屏
从元件区拾取光屏，放置到导轨上。激光直接打在光屏上，UnifiedScreenPanel 显示红点追踪画面。

### 第二步：调节光路至光屏中心
进入特写视角，微调激光器位置（LaserEmitterMover，WASD ±0.035m），使红点对准光屏中心，确保光路准直。

### 第三步：起偏器与检偏器消光
1. 依次放置起偏器和检偏器到导轨上
2. 旋转检偏器使起偏器与检偏器透振方向正交
3. 观察光屏上光斑逐渐变暗直至消光 —— 验证马吕斯定律

光路状态：激光 → 起偏器(∥竖直) → 检偏器(∥水平) → 光屏（暗）

### 第四步：放置晶体 → 放置扩束镜 → 观察锥光干涉
1. 在起偏器与检偏器之间放入晶体盒
2. 在晶体盒前放入扩束镜（将会聚光变为锥光入射晶体）
3. 当扩束镜、晶体盒、光屏三者都在导轨上时，UnifiedScreenPanel 自动切换到锥光干涉模式
4. 双击晶体盒进入特写视角，操作旋钮调节晶体俯仰/偏航，实时观察锥光干涉图样变化

### 第五步：取下光屏与扩束镜 → 放置光电接收器 → 进入实验
1. 取下光屏和扩束镜（恢复平行光路）
2. 在晶体盒后方放置光电接收器
3. 开机 → 微调对准 → 进入电光调制实验：
   - 极值法测 Vπ（RecordManager 记录电压-功率数据）
   - Scene4 示波器观察倍频失真

**Why:** 用户亲自口述的正确实验步骤顺序，之前的理解有误（先放晶体后放扩束镜、先锥光观察后消光验证）
**How to apply:** 任何涉及实验流程的讨论都应以此为权威参考顺序
